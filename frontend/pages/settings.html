Open vault

Each account gets its own local vault, auto-created on first use — no setup required. In production, point OBSIDIAN_VAULT_ROOT at a directory containing one real, synced Obsidian vault per user (e.g. via Obsidian Sync or a filesystem sync tool) instead of the default local storage location.

AI provider connection
Checking…

The active AI provider is chosen server-side and never exposed to the browser. By default this application uses Claude — set ANTHROPIC_API_KEY (and optionally CLAUDE_MODEL) as backend environment variables and restart the server. Set AI_PROVIDER=gemini with GOOGLE_API_KEY to use Gemini for chat/reasoning instead. There is no local/Ollama option. No code changes are required to switch providers, and credentials are never sent to or stored in the browser.

Checking…

Generated documents (and future images/audio/video) are written through the StorageProvider abstraction. The local provider writes real files under storage/ on the backend with no credentials required; production can point STORAGE_PROVIDER at an S3-compatible backend once configured, without any application code changes.
